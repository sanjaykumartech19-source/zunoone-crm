Integrations

Connect the channels your customers already use

Messaging apps go live in minutes. Everything else connects through a clean REST API and outbound webhooks — so Zuno One fits the stack you already run.

Channels

Six channels, one queue

WhatsApp

Link a real WhatsApp number by scanning a QR code — no Business API application, no waiting. Media, delivery status and full chat history come across, and replies send straight from the inbox.

Setup guide →

Instagram

Bring Instagram DMs in through your linked Facebook Page and a Meta app token. Comments-to-DM and story replies land in the same thread list as everything else.

Setup guide →

Facebook Messenger

Connect your Facebook Page via the Meta Graph API. Messenger conversations route to the right agent with the same rules as your other channels.

Setup guide →

Email

Gmail & Google Workspace via OAuth, or Outlook / Microsoft 365, Yahoo, iCloud, Zoho and any IMAP / SMTP mailbox with just a login (app password where required). Threads become conversations and replies go out as proper threaded email from your address.

Setup guide →

TikTok Your own API access

Connect a TikTok Business account that has Messaging API access from TikTok (granted to approved partners). Your token, your account — DMs and comment replies route into the same shared queue, with the same assignment rules and reporting as every other channel.

Snapchat Your own API access

Connect a Snapchat business profile that has messaging access from Snap. Conversations are handled alongside every other channel — one queue, one history, one set of rules.

Developers

A REST API and webhooks for everything else

Push a message from your backend, sync contacts from your CRM, or fire an event into a warehouse. Authenticate with a workspace API key you can rotate anytime.

  • Endpoints for messages, contacts, labels, events
  • Signed outbound webhooks on every event
  • Works with Zapier, Make and n8n out of the box

Website chat

Put the chat widget on any site

One line of script turns any website into a channel — visitor chats land in the same shared inbox, run the same routing and automations, and can hand off to WhatsApp or email.

Shopify

Add the widget to your storefront theme so product and order questions come straight to your team. Sync orders and customer data through Make, n8n or Zapier.

Wix

Drop the script into Wix's custom-code area. No plugin to maintain — the widget loads on every page and your inbox does the rest.

WordPress

Paste the snippet in your theme footer or a code-snippet plugin. Works on any WordPress or WooCommerce site.

Any HTML site

Squarespace, Webflow, a hand-built site — anywhere you can add a <script> tag, the widget works. Set the greeting, colour and routing in Settings.

Tools & workspace

Connect the rest of your stack

Google Calendar

Connect one Google account with OAuth and see a contact's upcoming and past meetings in the conversation sidebar, matched by email — date, time, host and response status, without leaving the inbox.

Zendesk

Add your Zendesk subdomain and an API token, then raise a ticket from any conversation — one click in the details panel, or automatically with a Create Zendesk ticket workflow action. The recent transcript and requester details come across.

Zapier · Make · n8n

Available today. Trigger on any inbound message or event and push to 6,000+ apps — CRMs, sheets, ticketing, data warehouses.
