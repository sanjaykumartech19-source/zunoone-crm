Features

Everything a support team needs, in one place

The shared inbox is just the start. Zuno One carries routing, a full automation engine, broadcasts, AI assistance, analytics and a developer API — so you can run every customer conversation from one screen.

Shared inbox

Every channel in one thread list

WhatsApp, Instagram, Messenger and Gmail land in a single queue, in real time. Full history, media, quoted replies, and private internal notes with @mentions so the team stays in sync.

  • Live updates — no refresh
  • Media, files and location
  • Internal notes and @mentions

A lightweight CRM that stays out of the way

Each person gets a profile — name, phone, email, the channels they've used. Add tags, drop an internal note, or set a follow-up reminder that pings you when it's due.

  • One profile across every channel
  • Tags, notes and custom status
  • Follow-up reminders

Organise the queue your way

Coloured labels applied to conversations, saved filters for the views your team lives in, and the same labels usable as conditions inside automations.

Routing & assignment

Send the right chats to the right people

Round-robin across a pool, or tick exactly which channels each agent handles. Agents get a restricted view — only their queue and their channels, nothing else.

  • Channel × agent matrix
  • Round-robin with availability
  • Agent-restricted dashboard

Automations

Put the repetitive work on autopilot

A rule engine with clear triggers, conditions and actions. Auto-reply after hours, route by keyword, escalate on no-reply, tag, set status, wait, or call a webhook.

  • Triggers: message in, keyword, no reply, status change
  • Actions: reply, AI reply, assign, tag, label, webhook, wait
  • Test a rule before it goes live

Broadcasts

Reach a segment without leaving the inbox

Pick a filtered set of contacts, write one message, and send. Watch delivered and failed counts tick up on a live progress bar, and pick up any replies in the same queue.

  • Segment by label, tag or channel
  • Live delivered / failed tracking
  • Replies flow back to the inbox

  • One-click suggested replies
  • Autopilot with keyword hand-off

Developer API

A REST API and webhooks for everything else

Send and read messages, manage contacts and labels, and subscribe to outbound webhooks for Zapier, Make, n8n or your own services. Authenticate with a workspace API key.

  • REST endpoints for messages, contacts, labels
  • Outbound webhooks on every event
  • Rotatable API keys per workspace

  • Per-workspace channels and team
