Six views, one dataset

See the work the way you need to

Every project opens in the layout that fits the moment — drag cards on a Board, scan a grouped List, edit a spreadsheet-style Table, plan on a Calendar, sequence on a Timeline (Gantt with a today marker and dependency-aware bars), or check a per-project Dashboard with completion, time logged and milestones.

  • Board · List · Table · Calendar · Timeline · Dashboard
  • Group by status, assignee or priority; filter by anyone, priority, sprint or search
  • Drag-and-drop with live sync across every open board
  • Task ids like WEB-42 on every card and row
Real task depth

Subtasks, dependencies, custom fields and more

Tasks carry everything a delivery team needs — nested subtasks with progress, "blocked by" dependencies that stop a task closing early, per-project custom fields (text, select, date, money…), tags, estimates, checklists, comments with @mentions, and a full activity log per task.

  • Subtasks with roll-up progress
  • Dependencies — a blocked task can’t be marked done
  • Custom fields shown as Table columns
  • Recurring tasks that spawn the next occurrence on completion
  • Milestones flagged on the board, calendar and timeline
Track effort and cadence

Time tracking and sprints

Start a timer or log minutes against any task; totals roll up to the card and the dashboard. Turn on sprints to date-box work, mark one active, and filter every view to it.

From chat to task

One button in the conversation

A "Create a task" action in the inbox details panel spins a task out of the open conversation — pre-filled with the customer’s name, the last message and a link back to the thread, dropped into your first project.

Message"can you also add onboarding?"

Across every project

Portfolio Overview and access control

Switch the module to Overview for a dashboard across all projects — KPI tiles (active, completed, overdue, at-risk, velocity, team load), a status donut, a progress-by-project chart, upcoming deadlines, team workload and a live activity feed. Give each teammate a tick-box list of exactly which projects and areas they can open.

  • Board / Overview layout toggle, remembered per person
  • Per-member project access — everything else stays hidden
  • Save any project as a reusable template
  • Editable per-project statuses, custom fields and sprints
